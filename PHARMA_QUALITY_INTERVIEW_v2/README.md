# PHARMA QUALITY INTERVIEW v2

사용자가 제공한 제약 모의면접 웹사이트 소스를 **참조**하여 만든 로컬 실행용 Streamlit 애플리케이션입니다.

## 포함한 기능

- 원본 `questions.js`에서 추출한 **315개 질문** (15개 직무×20 + 인사 15)
- 원본 `app.js`에서 추출한 **15개 직무 / 세부 업무 선택값 / 세부 질문 13개**, 네 면접관 역할 + **독립적으로 작성한 DI 직무 20문항** (총 335문항/16개 직무)
- 8문항/12문항, 인성·직무·통합, 연습·실전 모드, 최근 질문 회피
- 최대 2개 꼬리질문 (API 사용 시 답변 맞춤 LLM 질문, 미사용 시 사전 작성된 규칙 기반)
- **지원 기업명과 채용공고를 입력해 기업 맞춤형 연습** (사용자 입력 자료로 취급)
- **OpenAI API 연동 시** 문맥 기반 점수(100점), 강점·개선점, 품질상 위험요소, 개선 답변 예시, 꼬리질문
- **API 미설정 시** 질문 연습 및 키워드·표현 점검 (점수 미제공)
- 브라우저 마이크로 녹음 후 API 음성 받아쓰기 (지원 브라우저)
- 로컬 SQLite 면접 기록, 질문은행 검색, Markdown 답변 저장, 기록 전체 삭제
- 기본 개인 경험 자료(선택적으로 수정) — 사용자의 GC-MS·QbD·PCR 경험 요약

## 실행 (Windows 10 / 11)

1. 압축을 해제하고 **`start_windows.bat`을 더블클릭**합니다. Python 3.11 이상이 필요합니다. 처음 한 번은 인터넷을 통해 Streamlit 및 OpenAI 라이브러리를 설치합니다.
2. 또는 터미널에서:
   ```bash
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
   ```
3. 브라우저에서 `http://localhost:8501` 로 접속합니다.
4. 왼쪽 **AI 설정**에서 API 키를 넣으면 LLM 평가가 작동합니다. 키가 없어도 연습할 수 있습니다.

## API 키 관리

- API 키는 코드와 SQLite에 저장하지 않습니다. 앱의 비밀번호 입력창 또는 환경변수 `OPENAI_API_KEY`를 사용하세요.
- ChatGPT Plus/Pro 구독과 OpenAI API는 별도입니다. API는 호출량만큼 요금이 발생할 수 있습니다.
- 설정에 입력한 개인 경험 자료와 답변은 LLM 평가 요청 시 API 제공자에게 전송됩니다.
- 선택한 모델이 계정에서 활성화되어 있지 않거나 API 사용 한도가 없으면 오프라인 점검으로 전환됩니다.

## 파일 구조

```text
app.py                        Streamlit 화면 및 면접 흐름
bank.py                       질문은행 읽기·질문 선정
storage.py                    로컬 SQLite 기록
evaluator.py                 오프라인 점검 및 API 평가
extract_questions.py           원본 JS 질문 및 직무 정보 추출
assets/app_theme.css          Streamlit UI 테마
assets/original_source/       사용자가 올린 4개 원본 파일 (보존)

data/di_extension.json        별도 작성한 DI 직무 20문항
start_windows.bat             Windows 시작 스크립트
```

## 사용상의 주의

- **AI가 부여한 점수는 학습 참고용 추정**이며 실제 면접 합격 가능성이나 GMP 준수 판정을 의미하지 않습니다. 회사별 SOP, 규제기관 원문은 직접 확인하세요.
- API가 없을 때 표시되는 점검은 **AI 지식 평가가 아닙니다**. 키워드·표현만 확인합니다.
- 개인정보가 포함될 수 있는 답변은 `local_data/interviews.sqlite3`에 저장됩니다. **이 프로젝트는 개인 컴퓨터에서 실행하는 용도**입니다. 공개 인터넷에 배포하려면 계정 로그인, 사용자별 DB 분리, 접근제어, 암호화 등의 추가 작업이 필요합니다.
- 포함된 원본 소스(`assets/original_source`)는 **개인 분석·참조** 목적으로 보존했습니다. 원본 사이트 코드·콘텐츠의 외부 공개 및 배포 권한은 확인되지 않았습니다. 따라서 압축파일을 제3자에게 재배포하거나 서비스에 공개하기 전 권리자의 허락을 확인하세요.
- 코드를 실행할 때 `extract_questions.py`는 JS를 실행하지 않고 문자열 데이터만 추출합니다.

## 설치 없이 간단히 체험하기

`quick_practice.html`을 더블클릭하면 브라우저에서 바로 열리는 **오프라인 질문·답변 연습용** 페이지가 실행됩니다. 이는 LLM 평가 기능이 없는 간이 버전입니다. AI 점수·개선 답변·맞춤 꼬리질문은 Streamlit 버전에서 API 키를 연결해야 이용할 수 있습니다.

## 자체 점검 범위

파이썬 구문 검사와 유닛테스트를 통과했지만, 프로젝트 제작 환경에 Streamlit 패키지가 없어 브라우저에서 실제 앱 기동까지는 검증하지 못했습니다. 사용자 PC에서 첫 실행 후 오류가 발생하면 실행 창의 오류 메시지를 공유하세요.
